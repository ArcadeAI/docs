# Install Arcade in Claude Desktop

Add Arcade through Claude Desktop's plugin marketplace. Chat gets tools and both skills. Cowork and Code also load the operator, commands, and supported routing hooks when you enable the plugin there.

<GuideOverview>
<GuideOverview.Outcomes>

Install Arcade in Claude Desktop and run a task against one of your apps.

</GuideOverview.Outcomes>

<GuideOverview.Prerequisites>

1. Claude Desktop with plugin marketplace support
2. An <SignupLink linkLocation="docs:agent-plugin-claude-desktop">Arcade account</SignupLink>

</GuideOverview.Prerequisites>

</GuideOverview>

<Callout type="info">
  Using Claude Code inside the desktop app? You can also install Arcade with
  the Claude Code marketplace commands below.
</Callout>

## Install the plugin

**Customize → Plugins → Add marketplace → Add from a repository** → paste:

```text
{{ARCADE_PLUGIN_REPO}}
```

Then install **Arcade** (`arcade@arcade`).

From Claude Code in the desktop app, or a terminal:

```bash
claude plugin marketplace add {{ARCADE_PLUGIN_REPO}}
claude plugin install arcade@arcade
```

If Claude Code is already open, run `/reload-plugins`.

No documented `claude://` link adds a marketplace. The steps on this page are the install.

## Tools only

If you only want the gateway without skills, skip the marketplace. Open **Settings → Connectors**, click **Add custom connector**, and paste:

```text
{{ARCADE_PLUGIN_GATEWAY_URL}}
```

Save, then start a new conversation. You get the same tools this way. You lose the skills that teach Claude how to chain tool calls across your apps. See [what you give up](/get-started/agent-plugin/tools-only#what-you-give-up).

## Sign in

Connecting Arcade signs you in and links Claude Desktop to the gateway. When a task needs an app, your agent gives you a browser sign-in link for the required permissions. After approval, Arcade stores the authorization. You may need to reconnect if the connection expires or a later task needs additional permissions. You can connect an app before you need it. See [signing in](/get-started/agent-plugin/tools-only#sign-in) for how the two layers fit together.

## Try it

Ask Claude for an outcome rather than naming a tool. The first time a task needs an app you have not authorized, Claude hands you a link. Approve it and the rest of the task continues, including steps that land in a different app.

See [sample prompts](/get-started/agent-plugin#try-it) on the main install page, or ask "What apps can Arcade use?"

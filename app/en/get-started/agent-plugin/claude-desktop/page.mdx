# Install Arcade in Claude Desktop

Claude Desktop Chat does not install agent plugins, so it gets Arcade tools through a connector instead. You still sign in to each app in the browser, and you still need no API key. You just do not get the plugin's skills, commands, or `arcade-operator` subagent.

<GuideOverview>
<GuideOverview.Outcomes>

Connect Claude Desktop to Arcade and run a task against one of your apps.

</GuideOverview.Outcomes>

<GuideOverview.Prerequisites>

1. Claude Desktop, updated to a version that supports custom connectors

</GuideOverview.Prerequisites>

</GuideOverview>

<Callout type="info">
  Using Cowork or Claude Code inside the Claude desktop app? Those do load agent
  plugins. Install the full plugin with [one
  command](/get-started/agent-plugin) instead.
</Callout>

## Add Arcade as a custom connector

1. Open **Settings → Connectors**
2. Click **Add custom connector**
3. Paste the Arcade gateway URL:

```text
{{ARCADE_PLUGIN_GATEWAY_URL}}
```

4. Save, then start a new conversation

## Sign in to your apps

The first time Claude reaches for an app, it returns a browser sign-in link. Approve it and Arcade holds the token from then on, so you only do this once per app.

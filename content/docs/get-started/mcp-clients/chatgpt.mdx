<Callout type="info">
  To use Arcade's hosted gateway and skills, [install the Arcade agent plugin](/en/get-started/agent-plugin).
  This guide connects ChatGPT to a gateway you configure.
</Callout>

This page is for agent developers who connect ChatGPT on the web to an Arcade [MCP Gateway](/en/operate/governance/mcp-gateways).

<GuideOverview>
<GuideOverview.Outcomes>

Connect ChatGPT to an Arcade MCP Gateway.

</GuideOverview.Outcomes>

<GuideOverview.Prerequisites>

1. Create an <SignupLink linkLocation="docs:chatgpt-client">Arcade account</SignupLink>
2. Create an [Arcade MCP Gateway](/en/operate/governance/mcp-gateways) and select the tools you want to use
3. Set the gateway's authorization to **Arcade Auth** or a [User Source](/en/operate/identity/user-sources)

</GuideOverview.Prerequisites>

</GuideOverview>

<Callout type="info">
  **Production end users with their own identities?** If your end users already sign in to Entra ID, Okta, Auth0, Clerk, or another OIDC provider, configure a [User Source](/en/operate/identity/user-sources) on your gateway. Arcade redirects each end user to your identity provider on sign-in and identifies them by an OIDC subject claim.
</Callout>

ChatGPT adds a remote MCP server from **Plugins**. Workspace permissions still apply, including who can create plugins that use MCP servers. See [Add a custom MCP server](https://developers.openai.com/api/docs/guides/custom-mcp-server).

<Steps>

### Add the gateway

1. Open [ChatGPT on the web](https://chatgpt.com) and go to **Plugins**.
2. Select the plus button, then **Add custom MCP server**.
3. Enter a name and, if you want, a description.
4. Under **Connection**, enter your MCP Gateway URL:

   ```text
   https://api.arcade.dev/mcp/<YOUR-GATEWAY-SLUG>
   ```

   If you self-host the Arcade Engine, use your Engine hostname in place of `api.arcade.dev`.
5. Set authentication to **OAuth** so ChatGPT runs the gateway's browser sign-in.
6. Review the risk warning and select **I understand and want to continue**.
7. Select **Create as a plugin**.

### Install and sign in

Find the plugin in your personal plugins, or in the workspace where you created it. Select **Install plugin**. Start a new chat, type `@`, and select the plugin. Sign in to Arcade in the browser when ChatGPT asks.

### Try it out

Ask ChatGPT to use a tool from the gateway. Name the plugin in the request when several apps could apply.

</Steps>

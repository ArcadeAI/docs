You can connect [Arcade MCP servers](/en/resources/integrations) to MCP-compatible clients and development environments to unlock powerful flows for your agents.

Every supported MCP client, including ChatGPT, Cursor, Claude Desktop, Claude Code, VS Code, GitHub Copilot, and Copilot Studio, connects to an Arcade [MCP Gateway](/en/operate/governance/mcp-gateways) over the Streamable HTTP transport. The gateway decides which tools the client can call: pick from Arcade-hosted toolkits (GitHub, Linear, Gmail, Slack, Google Calendar, Notion, Jira, Confluence, and dozens more in the [integrations catalog](/en/resources/integrations)), from [remote MCP servers](/en/operate/governance/remote-mcp-servers) you registered, and from your own [custom MCP servers](/en/build/create-tools/tool-basics/build-mcp-server) hosted with [Arcade Deploy](/en/build/arcade-deploy).

## Use the hosted gateway

To connect your agent to apps through Arcade's hosted gateway, [install the Arcade agent plugin](/en/get-started/agent-plugin). This guide connects your client to a gateway you configure.

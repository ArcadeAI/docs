<Callout type="info">
  To use Arcade's hosted gateway, [install the Arcade agent plugin](/en/get-started/agent-plugin).
  This guide connects your client to a gateway you configure.
</Callout>

<GuideOverview>
<GuideOverview.Outcomes>

Connect GitHub Copilot to an Arcade MCP Gateway.

</GuideOverview.Outcomes>

<GuideOverview.Prerequisites>

1. Create an <SignupLink linkLocation="docs:github-copilot-client">Arcade account</SignupLink>
2. Get an [Arcade API key](/en/get-started/setup/api-keys)
3. Create an [Arcade MCP Gateway](/en/operate/governance/mcp-gateways) and select the tools you want to use

</GuideOverview.Prerequisites>

</GuideOverview>

<Callout type="info">
  **Production end users with their own identities?** If your end users already sign in to Entra ID, Okta, Auth0, Clerk, or another OIDC provider, configure a [User Source](/en/operate/identity/user-sources) on your gateway. Arcade redirects each end user to your identity provider on sign-in and identifies them by an OIDC subject claim.
</Callout>

### Set up GitHub Copilot

<Tabs
  items={["VS Code", "JetBrains IDEs", "Visual Studio", "Eclipse", "Xcode"]}
  storageKey="copilotIDE"
>
  <Tabs.Tab>
    In VS Code, Github Copilot will automatically detect the configured MCP
    servers. Read the [VS Code
    instructions](/en/get-started/mcp-clients/visual-studio-code) to set both of
    them up.
  </Tabs.Tab>
  <Tabs.Tab>
    <Callout type="info">
      The GitHub Copilot extension for JetBrains IDEs does not currently support remote MCP servers with Dynamic Client Registration. To use an Arcade MCP Gateway with GitHub Copilot on a JetBrains IDE, you must configure the MCP gateway as `Arcade Headers` in the dashboard.
    </Callout>

    1. In the lower right corner, click the GitHub Copilot icon.
    2. From the menu, select "Open Chat", make sure you are in Agent mode, then click the tools icon.
    3. A dialog will open with a list of tools. On the bottom left, select **Add MCP Tools**.
    4. This will open the `mcp.json` file in the editor. In the `mcp.json` file, define your MCP servers.

    <Tabs items={["Arcade Headers", "Arcade Auth"]} storageKey="preferredMCPAuthMode">
      <Tabs.Tab>

      ```json
      {
        "servers": {
          "mcp-arcade": {
            "url": "https://api.arcade.dev/mcp/<YOUR-GATEWAY-SLUG>",
            "requestInit": {
              "headers": {
                "Authorization": "Bearer {arcade_api_key}",
                "Arcade-User-ID": "{arcade_user_id}"
              }
            }
          }
        }
      }
      ```

      </Tabs.Tab>
      <Tabs.Tab>
        The GitHub Copilot extension for JetBrains IDEs does not currently support remote MCP servers with Dynamic Client Registration. To use an Arcade MCP Gateway with GitHub Copilot on a JetBrains IDE, you must configure the MCP gateway as `Arcade Headers` in the dashboard.
      </Tabs.Tab>
    </Tabs>

    Once you save the `mcp.json` file, a start button will appear over the new server name. Click it to start the MCP server.
    <Image
      alt={"Start the MCP server"}
      className="max-w-full mt-4"
      src={"/images/mcp-gateway/github-copilot/jetbrains/start-mcp.png"}
      width={JETBRAINS_START_WIDTH / IMAGE_SCALE_FACTOR}
      height={JETBRAINS_START_HEIGHT / IMAGE_SCALE_FACTOR}
    />

    <Callout type="important">
      MCP tools are only available in Agent mode.
    </Callout>

  </Tabs.Tab>
  <Tabs.Tab>
    <Callout type="info">
      The GitHub Copilot extension for Visual Studio does not currently support every remote MCP server with Dynamic Client Registration. To use an Arcade MCP Gateway with GitHub Copilot on Visual Studio, you must configure the MCP gateway as `Arcade Headers` in the dashboard.
    </Callout>
    In Visual Studio,

    1. In the menu bar, select **View**, then **GitHub Copilot Chat**.
    2. At the bottom of the chat panel, select **Agent**.
    3. Select the tools icon, then the plus icon in the tool picker.
    4. In **Configure MCP server**, set **Server ID** (for example, `mcp-arcade`), set **Type** to **HTTP/SSE**, and paste your MCP Gateway URL. For **Arcade Headers**, add `Authorization` and `Arcade-User-ID` under **Headers**, then select **Save**.

    The saved entry uses `requestInit` for those headers:

    <Tabs items={["Arcade Headers", "Arcade Auth"]} storageKey="preferredMCPAuthMode">
      <Tabs.Tab>

      ```json
      {
        "servers": {
          "mcp-arcade": {
            "url": "https://api.arcade.dev/mcp/<YOUR-GATEWAY-SLUG>",
            "requestInit": {
              "headers": {
                "Authorization": "Bearer {arcade_api_key}",
                "Arcade-User-ID": "{arcade_user_id}"
              }
            }
          }
        }
      }
      ```

      </Tabs.Tab>
      <Tabs.Tab>
        The GitHub Copilot extension for Visual Studio does not currently support every remote MCP server with Dynamic Client Registration. To use an Arcade MCP Gateway with GitHub Copilot on Visual Studio, you must configure the MCP gateway as `Arcade Headers` in the dashboard.
      </Tabs.Tab>
    </Tabs>

  </Tabs.Tab>
  <Tabs.Tab>
    <Callout type="info">
      Use **Arcade Headers** for this setup. GitHub's Copilot docs show an OAuth sign-in only for GitHub's own MCP server.
    </Callout>

    1. Select the Copilot icon in the status bar at the bottom of Eclipse.
    2. Select **Open Chat**, then **Configure Tools...**. You can also select **Edit preferences**, expand **GitHub Copilot**, and select **MCP**.
    3. Under **Server Configurations**, add the gateway and select **Apply**:

    ```json
    {
      "servers": {
        "mcp-arcade": {
          "url": "https://api.arcade.dev/mcp/<YOUR-GATEWAY-SLUG>",
          "requestInit": {
            "headers": {
              "Authorization": "Bearer {arcade_api_key}",
              "Arcade-User-ID": "{arcade_user_id}"
            }
          }
        }
      }
    }
    ```

    Set the gateway's **Authorization** field to **Arcade Headers** in the dashboard.

  </Tabs.Tab>
  <Tabs.Tab>
    <Callout type="info">
      Use **Arcade Headers** for this setup. GitHub's Copilot docs show an OAuth sign-in only for GitHub's own MCP server.
    </Callout>

    1. Open **GitHub Copilot for Xcode** settings. In an Xcode workspace, select **Editor → GitHub Copilot → Open GitHub Copilot for Xcode Settings**.
    2. Select the **MCP** tab, then **Edit Config**.
    3. Add the gateway:

    ```json
    {
      "servers": {
        "mcp-arcade": {
          "url": "https://api.arcade.dev/mcp/<YOUR-GATEWAY-SLUG>",
          "requestInit": {
            "headers": {
              "Authorization": "Bearer {arcade_api_key}",
              "Arcade-User-ID": "{arcade_user_id}"
            }
          }
        }
      }
    }
    ```

    Set the gateway's **Authorization** field to **Arcade Headers** in the dashboard.

  </Tabs.Tab>
</Tabs>

1. Open the chat pane.
1. Make sure you are in **Agent** mode.
1. Ask the agent to use a tool.

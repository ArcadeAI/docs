For agent developers, the Arcade plugin connects your coding agent or desktop client to apps through Arcade's hosted gateway. Sign in with your Arcade account. You don't need an Arcade API key or a gateway configuration.

<GuideOverview>
<GuideOverview.Outcomes>

Install the Arcade agent plugin in a supported client and connect to its hosted gateway.

</GuideOverview.Outcomes>

<GuideOverview.Prerequisites>

- A [supported client](/en/get-started/agent-plugin/whats-included#client-support): Cursor, Claude Code, VS Code, GitHub Copilot CLI, Codex, Claude Desktop, or Grok Bot
- An <SignupLink linkLocation="docs:agent-plugin-install">Arcade account</SignupLink>
- For Claude Code, Claude Cowork, Cursor CLI, GitHub Copilot CLI, and VS Code Copilot sessions: [Node.js](https://nodejs.org/) on the host's `PATH`

</GuideOverview.Prerequisites>

</GuideOverview>

## Install

<Tabs items={["Claude Code", "Codex", "Cursor", "VS Code", "Copilot CLI", "Claude Desktop", "Grok Bot", "Other"]}>
<Tabs.Tab>

1. Add the Arcade marketplace and install the plugin:

   ```bash
   claude plugin marketplace add ArcadeAI/arcade-plugin
   claude plugin install arcade@arcade
   ```

2. Run `/reload-plugins` if Claude Code is already open.
3. Open `/mcp`, select **arcade**, and sign in to Arcade in the browser when prompted.
4. Run `/arcade:try-arcade` to start.

5. Choose `@Arcade` or invoke `$arcade:try-arcade` to start.

**Team marketplace**

1. An admin opens **Dashboard → Plugins & MCPs → Team Marketplaces → Add Marketplace → Import from Repo** and pastes `https://github.com/ArcadeAI/arcade-plugin`.
2. The admin adds Arcade to the marketplace and sets access in **Marketplace Settings**. For automatic updates from GitHub, enable **Auto Refresh** and install the Cursor GitHub App on the repository.
3. Open **Customize**, find **Arcade**, and select **Install**.
4. Connect the **arcade** MCP server and sign in to Arcade in the browser when prompted.
5. Run `/try-arcade` to start.

See [Cursor's marketplace instructions](https://cursor.com/docs/plugins#add-a-team-marketplace) for access and refresh settings.

<details>
<summary>Local installation</summary>

For an individual plan, or a Teams or Enterprise plan with **Allow Local Plugin Imports** enabled:

Cursor loads each folder under `~/.cursor/plugins/local` as a plugin root. It looks for `plugin.json` or `.cursor-plugin/plugin.json` in that folder ([Test plugins locally](https://cursor.com/docs/plugins)). In this repository those files are `plugin/plugin.json` and `plugin/.cursor-plugin/plugin.json`. Clone the repository somewhere else, then copy `plugin/` into the local plugin folder.

1. Clone the repository and copy the plugin folder:

   ```bash
   git clone https://github.com/ArcadeAI/arcade-plugin.git ~/src/arcade-plugin
   mkdir -p ~/.cursor/plugins/local
   rm -rf ~/.cursor/plugins/local/arcade
   cp -R ~/src/arcade-plugin/plugin ~/.cursor/plugins/local/arcade
   ```

2. Run **Developer: Reload Window**.
3. Open **Customize** and confirm Arcade is present.
4. Connect the **arcade** MCP server and sign in to Arcade in the browser when prompted.
5. Run `/try-arcade` to start.

Do not symlink to a folder outside `~/.cursor/plugins/local/`. Cursor ignores external symlink targets. To update, run `git pull` in `~/src/arcade-plugin`, copy `plugin/` over `~/.cursor/plugins/local/arcade` again, and run **Developer: Reload Window**:

```bash
cd ~/src/arcade-plugin
git pull
rm -rf ~/.cursor/plugins/local/arcade
cp -R ~/src/arcade-plugin/plugin ~/.cursor/plugins/local/arcade
```

1. Open the Command Palette and select **Chat: Install Plugin From Source**.
2. Paste the repository URL:

   ```text
   https://github.com/ArcadeAI/arcade-plugin
   ```

3. Turn on `chat.plugins.enabled` if needed, then reload VS Code.
4. Confirm **Arcade** appears under **Agent Plugins → Installed**.
5. Run **MCP: List Servers**, select **arcade**, and choose **Start Server**.
6. Sign in when prompted, then return to VS Code and continue the original task.
7. Run `/arcade:try-arcade` to start.

Grok Bot loads the `try-arcade` and `scale-arcade` skills and the Arcade MCP server as a connector. Hooks, commands, and the `arcade-operator` subagent do not run.

```text
https://api.arcade.dev/mcp/arcade
```

The connector namespace does not always use the name `arcade`. A team connector can use another name, such as `Arcade Full-Suite`. `try-arcade` calls `Arcade_SelectTools` and `Arcade_UseTool` on the namespace that exposes those tools.

Sign in to Arcade in the browser when a task needs an app that is not connected. Each app has its own sign-in. On a Team Bot, a plugin that signs in with an account uses the person talking to the Bot. Each teammate connects their own account the first time they need it.

Grok Bot's docs cover connecting an app, installed plugins, team connector policy, Team Bot sign-in, and authentication problems:

- [Use the computer and apps](https://docs.x.ai/grok-bot/computer-and-apps): connect an app
- [Settings and notifications](https://docs.x.ai/grok-bot/settings-and-notifications): installed plugins
- [Grok Bot for teams and enterprises](https://docs.x.ai/grok-bot/teams-and-enterprises): team connector policy
- [Team Bots](https://docs.x.ai/grok-bot/team-bots): account sign-in on a Team Bot
- [Troubleshooting](https://docs.x.ai/grok-bot/troubleshooting): a plugin that does not install or authenticate

Ask "What apps can Arcade use?" to start.

<Tabs.Tab>

Your client must support remote HTTP MCP servers and browser sign-in. This connection includes tools only; it does not install the plugin's skills, subagent, or commands.

1. Add an HTTP MCP server with this URL in your client's MCP settings:

   ```text
   https://api.arcade.dev/mcp/arcade
   ```

2. Sign in to Arcade in the browser when prompted, then return to your client.

## Connect apps

[Gateway sign-in and app authorization are separate](/en/learn/server-level-vs-tool-level-auth). After connecting the gateway during installation, ask your agent to use an app. If the app needs authorization, follow the browser sign-in link and approve the required permissions.

Return to your agent after sign-in and continue the task. To manage connections, ask "Show my connected apps" or "Connect Google."

Some tools require a provider API key or another secret. See [default-project setup](/en/get-started/agent-plugin/whats-included#projects-and-secrets) before using those tools.

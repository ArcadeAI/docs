## PagerDuty + Arcade integration benefits

- **Triage incidents from your AI agent.** List incidents filtered by status, urgency, service, team, or time, read an incident's details and log entries, then acknowledge, resolve, reopen, or reassign it without leaving the agent.
- **Find out who's on call.** Query on-call entries, schedules, and escalation policies to see who's responsible for a service and how PagerDuty escalates its incidents.
- **Look up the people and services involved.** Search users by name or email, and read teams, their members, and services.
- **Use the agent you already have.** The tools work in any MCP client that connects to an Arcade MCP gateway, such as Claude, Cursor, or VS Code, and in agents you build with the Arcade SDKs.
- **Request only the access each tool needs.** Each tool asks for the narrowest PagerDuty OAuth scopes for its job and acts as the PagerDuty user who authorized it.
- **Keep credentials away from the model.** Arcade stores each user's PagerDuty token and calls PagerDuty on the server, so the token never reaches the language model.

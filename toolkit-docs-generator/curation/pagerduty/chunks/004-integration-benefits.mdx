## PagerDuty + Arcade integration benefits

- **Triage incidents from your agent:** list, read, acknowledge, resolve, reopen, and reassign incidents.
- **Find out who's on call** from on-call entries, schedules, and escalation policies.
- **Use the agent you already have:** any MCP client connected to an Arcade MCP gateway, such as Claude, Cursor, or VS Code.
- **Least-privilege access:** each tool requests only the scopes it needs and acts as the user who authorized it. Arcade keeps the token away from the language model.

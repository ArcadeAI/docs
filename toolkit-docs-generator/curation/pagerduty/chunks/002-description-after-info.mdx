<Callout type="info">
  On Arcade Cloud, these tools use Arcade's PagerDuty app, which a PagerDuty
  administrator installs once per account. See the [integration
  walkthrough](#integration-walkthrough). If you self-host the Arcade Engine, or
  you're building an agent for people who aren't members of your Arcade
  project, register your own **Scoped OAuth** app and configure the [PagerDuty
  auth provider](/references/auth-providers/pagerduty). Classic OAuth apps
  don't support the per-resource scopes these tools request.
</Callout>

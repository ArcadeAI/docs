<Callout type="warning" title="Scoped PagerDuty OAuth">
  Register a **Scoped OAuth** PagerDuty app with the scopes listed in the
  [PagerDuty auth provider](/references/auth-providers/pagerduty#permissions).
  Classic OAuth apps don't support the per-resource scopes these tools
  request.
</Callout>

## Integration walkthrough

### In PagerDuty

A PagerDuty administrator installs Arcade's PagerDuty app once for the whole account. Until then, nobody in the account can authorize it.

1. Sign in to PagerDuty as a user with the Admin or Account Owner role.
2. Go to `https://<your-subdomain>.pagerduty.com/oauth-apps/PHRMXL1`, where `<your-subdomain>` is the first part of your PagerDuty web address.
3. Review the app details and the scopes it requests, then click **Install on your account**.

If you aren't an administrator, open the same page and click **Copy install link** to send the link to one.

Installing the app doesn't grant access on its own. Each user authorizes Arcade the first time they use a PagerDuty tool. Arcade doesn't use PagerDuty's Events API, so you don't need to add an integration to a service or copy an integration key.

### In Arcade

**1. Create an MCP gateway with the PagerDuty tools**

1. Sign in to the [Arcade dashboard](https://app.arcade.dev) and select **MCP gateways**.
2. Click **Create MCP gateway**.
3. Under **Name it**, enter a name such as `PagerDuty`.
4. Under **Select apps**, find **PagerDuty** and select it to add all of its tools.
5. Under **Choose who connects**, select **Members of this Project**.
6. Click **Create MCP gateway**.

For the other gateway options, see [Create via Dashboard](/operate/governance/mcp-gateways/create-via-dashboard).

**2. Connect your MCP client**

In the **MCP gateways** list, open the gateway's actions menu, select **Connect to client**, and follow the steps for your client. [Connect to MCP Clients](/get-started/mcp-clients) has a guide for each supported client.

**3. Authorize PagerDuty**

1. Ask your agent a PagerDuty question, such as "Which PagerDuty incidents are open right now?"
2. The first PagerDuty tool call returns an authorization link. Open it, and sign in to Arcade if prompted.
3. Sign in to PagerDuty, review the requested scopes, and click **Submit Consent**.
4. Return to your agent. If it doesn't continue on its own, ask again.

To try the tools without an MCP client, open **Playground** in the Arcade dashboard, click **Select Tools**, add the PagerDuty tools, and ask the same question.

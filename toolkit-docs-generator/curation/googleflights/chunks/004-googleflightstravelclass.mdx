## GoogleFlightsTravelClass

Defines the travel class options for flights.

- **`ECONOMY`**: Economy class.
- **`PREMIUM_ECONOMY`**: Premium economy class.
- **`BUSINESS`**: Business class.
- **`FIRST`**: First class.

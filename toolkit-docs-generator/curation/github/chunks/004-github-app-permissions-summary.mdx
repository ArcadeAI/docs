## GitHub App Permissions Summary

When creating your GitHub App, you'll need to grant specific permissions. Here's a quick reference of which tools require which permissions:

### Repository Permissions

| Permission | Level | Required For |
|------------|-------|--------------|
| **Contents** | Read | All repository and pull request tools, getting file contents |
| **Contents** | Write | Creating/updating files, creating branches, merging PRs |
| **Issues** | Read & Write | Issue management, PR assignments, managing labels (Issues) |
| **Pull requests** | Read & Write | Pull request management, reviews, managing labels (PRs) |
| **Metadata** | Read | All tools (automatically granted) |
| **Statuses** | Read | `CheckPullRequestMergeStatus` |

### Organization Permissions

| Permission | Level | Required For |
|------------|-------|--------------|
| **Members** | Read | Projects, collaborators, org repos, user search |
| **Projects** | Read & Write | All Projects V2 tools |

### User Permissions

| Permission | Level | Required For |
|------------|-------|--------------|
| **Read user profile** | Read | User context tools, review workload |
| **Act on behalf of user** | Enabled | `SetStarred` (starring repositories) |

### Tools by Permission Requirements

<details>
<summary><b>Basic Repository Access</b> (Contents Read + Metadata)</summary>

- `GetRepository`
- `CountStargazers`
- `ListStargazers`
- `ListRepositoryActivities`
- `GetFileContents`

</details>

<details>
<summary><b>Repository Write</b> (Contents Write + Metadata)</summary>

- `CreateBranch`
- `CreateOrUpdateFile`
- `UpdateFileLines`

</details>

<details>
<summary><b>Issue Management</b> (Contents Read + Issues + Metadata)</summary>

- `CreateIssue`
- `UpdateIssue`
- `GetIssue`
- `ListIssues`
- `CreateIssueComment`
- `ListRepositoryLabels`
- `ManageLabels` (for issues)

</details>

<details>
<summary><b>Pull Request Read</b> (Contents + Pull requests Read + Metadata)</summary>

- `ListPullRequests`
- `GetPullRequest`
- `ListPullRequestCommits`
- `ListReviewCommentsOnPullRequest`
- `CheckPullRequestMergeStatus` (+ Statuses)

</details>

<details>
<summary><b>Pull Request Write</b> (Contents Read + Pull requests Write + Metadata)</summary>

- `UpdatePullRequest`
- `CreatePullRequest`
- `SubmitPullRequestReview`
- `ManagePullRequest`
- `ManagePullRequestReviewers`
- `CreateReviewComment`
- `CreateReplyForReviewComment`
- `ResolveReviewThread`
- `ManageLabels` (for pull requests)
- `MergePullRequest` (+ Contents Write)

</details>

<details>
<summary><b>Organization Tools</b> (Contents + Metadata + Members)</summary>

- `ListOrgRepositories`
- `SearchMyRepos`
- `ListRepositoryCollaborators`
- `AssignPullRequestUser` (+ Issues Write)

</details>

<details>
<summary><b>Projects V2</b> (Contents + Metadata + Projects + Members)</summary>

- `ListProjects`
- `ListProjectItems`
- `SearchProjectItem`
- `ListProjectFields`
- `UpdateProjectItem` (Projects Write)

</details>

<details>
<summary><b>User Context</b> (Contents + Metadata + Read user profile)</summary>

- `WhoAmI` (+ Members)
- `GetUserRecentActivity`
- `GetUserOpenItems`
- `GetReviewWorkload` (+ Pull requests Read)

</details>
